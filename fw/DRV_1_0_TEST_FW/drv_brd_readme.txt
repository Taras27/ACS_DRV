

		Прошивка призначена для функціональної перевірки 
	плати DRV_BOARD, після стадії напайки компонентів.
	
	Алгоритм перевірки наступний:
	
		1. Подати живлення на розєм P10 в діапазоні 12 - 24 VDC;

		2. Підключити USB-CAN перетворювач до роз'єму Р6 (CAN BAUDRATE: 500 kbps);
		
		3. Підключити USB-RS485 перетворювач до роз'ємів P2, P13 та Р12.
		
		4. Запустити програму для перетворювача, 
			USB-CAN із наступними налаштуваннями CAN шини:
			
				- DLC - 8
				- Baudrate - 500 kbps
				- Mode - Standart
				
		5. На CAN шині очікується повідомлення із наступними параметрами та інтервалом 100 ms.:
		
			ID - 0x011
			DCL - 0x08
			DATA: 0x01 0x02 0x03 0x04 0x05 0x06 0x07 0x08
		
		6. Запустити програму (YAT https://sourceforge.net/projects/y-a-terminal/) 
			для перетворювача, USB-RS485 із наступними налаштуваннями COM PORT:
			
				- baudrate 115200
				- Data bits 8 
				- Parity None 
				- Stop bits 1
		
		7. На інтерфейсі RS485 очікується повідомлення з інтервалом 100 ms.:
		
			значення [ index ] - в діапазоні 1 - 3 в залежності 
			до якого розєму підключений USB-RS485 перетворювач.
		
			- "Hello from drv board: UART Transport [index]!!!"
			
		8	Створити нове вікно в програмі (YAT https://sourceforge.net/projects/y-a-terminal/) 
			для USB інтерфейсу із наступними налаштуваннями COM PORT:
			
				- baudrate 115200
				- Data bits 8 
				- Parity None 
				- Stop bits 1
			
		9. На інтерфейсі USB (baudrate 115200, Data bits 8, Parity None, Stop bits 1) 
			очікується повідомлення з інтервалом 100 ms.:
			
			- значення [ index ] - залежить від типу плати 
			та від напаяних резисторів перемичок [ R22, R23, R24, R25, R26, R27 ]
			
			- для плати DRV_BOARD очікуване ID 0xA1

			- "DRV_BOARD_ID [ index ]: CDC"
			
		10. Для перевірки кінцевих вимикачів, які підключаються до роз'ємів
			Р3, P4, P5, P6, P7, P8.
			
			- Для перевірки функціональності треба почергово на вищезгаданих розємах
			замкнути 2 контакти (для імітації спрацювання кінцевика), коли контакт 
			замкнутий, загориться відповідний світлодіод (LD1, LD2, LD3).
